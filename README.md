# FatturaXML → Excel/CSV (FatturaPA 100% Offline)

Convertitore batch di **fatture elettroniche italiane (FatturaPA)** da file `.xml` (e `.xml.p7m` firmati nella versione Desktop Pro) in un **file CSV pronto per Excel** (UTF-8 con BOM, separatore `;`, virgola decimale, protezione da formula-injection).

👉 **[Prova subito la Demo Web Gratuita (100% client-side)](https://skappax.github.io/fattura-xml-csv/)**

## Perché usarlo
- **Privacy totale (100% Offline):** nessun file viene caricato su server esterni. Il parsing avviene interamente sul tuo dispositivo.
- **Pronto per Excel italiano:** doppio clic sul CSV esportato — colonne pulite (`File`, `Tipo`, `Numero`, `Data`, `Cedente`, `P.IVA/CF`, `Imponibile`, `IVA`, `Totale`), importi con virgola e totali già allineati.
- **Ideale per Partite IVA, forfettari, PMI e studi contabili:** trasforma una cartella di fatture XML/P7M ricevute dallo SdI in un foglio di calcolo ordinato in pochi secondi.
